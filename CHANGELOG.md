## [0.1.0] - 2026-10-04

First release.

### Added
- Extraction of every decoded frame of a local video into native-resolution RGB PNGs with exact presentation timestamps. No temporal sampling or deduplication.
- MCP server with ordered image batches, frame and time navigation, contact sheets and pixel comparisons.
- Persistent delivery coverage and explicit agent observation notes, with gaps to resume from.
- Command-line interface and a local browser viewer.
- Python 3.10+ support and the MIT license.
